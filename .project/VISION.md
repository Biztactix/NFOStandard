# Vision

## Mission
Create a unified, open standard for .nfo metadata files that covers 95% of media use cases, eliminating the need for each application to reinvent its own format.

## Goals
1. **Universal adoption** — Become the de facto standard for media metadata in .nfo files
2. **Comprehensive coverage** — Support all major media types (movies, TV, music, podcasts, audiobooks, anime, etc.)
3. **Extensibility** — Allow applications to extend the schema for niche use cases without breaking compatibility
4. **Simplicity** — Keep the schema easy to understand and implement for developers
5. **Interoperability** — Enable seamless metadata exchange between different media applications

## Non-Goals
- Replacing existing database formats (this is a file interchange format)
- Defining streaming/playback metadata
- DRM or rights management
